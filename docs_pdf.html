1. Executive Summary & Business Objectives

The EquipmentsDekho Partners Brand Portal is a specialized enterprise SaaS platform built for industrial machinery manufacturers, brand principals, and authorized equipment distribution networks across India.

In the heavy machinery marketplace, buyers require high-touch sales interactions, technical specifications, and official quotation dispatches. This platform enables brand partners to ingest high-intent buyer inquiries in real time, route them instantly to field sales operators based on geographic territory boundaries, and manage the complete sales lifecycle from first customer inquiry to deal closure.

Key Business Drivers:

  • Instant Inbound Demand Ingestion: Captures equipment inquiries and quotation requests directly from the EquipmentsDekho marketplace without manual re-entry.
  • Territory Integrity: Strict boundary enforcement ensures regional dealers and field operators only access leads originating in their assigned states and cities.
  • Server-Driven Dynamic Capabilities: Menus, permissions, and module views are not hardcoded on the client; they adapt dynamically based on server-side permission contracts.
  • Workload-Balanced Auto-Routing: Prevents sales burnout and lead stagnation by routing unassigned leads to qualified Sub-Admins with the lowest open deal burden.
  • Tamper-Resistant Audit Trail: Every call, note, meeting, quotation dispatch, and assignment override is preserved in an immutable chronological timeline.

5. Authentication, Session & Security Architecture

Authentication is managed through a centralized state provider in AuthContext.jsx, interacting directly with authApi.js and the Axios network interceptor layer.

5.1 Authentication Flow:

Step 1: Credential SubmissionPOST
User submits username and password via Login.jsx to endpoint /premium-brand-login.
↓
Step 2: Token Issuance & Role NormalizationSECURITY
Backend responds with JWT token and user record. roleUtils.normalizeUserType() validates user_type. Unknown roles are immediately rejected.
↓
Step 3: Storage & Interceptor InjectionSTORAGE
Token is stored in localStorage. The Axios request interceptor attaches Authorization: Bearer <token> to all subsequent requests.
↓
Step 4: Startup Session Validation & 401 GuardVALIDATION
On page reload, fetchProfile() calls POST /profile. Any 401 response wipes credentials and forces redirection to /login without infinite reload loops.
Critical Security Implementation Rule
The application strictly refuses to default missing or malformed user roles to Admin. If a user record lacks an explicit user_type: "admin" or "sub_admin", the normalized role evaluates to null, and protected route access is immediately blocked.

6. Multi-Tenant Role-Based Access Control (RBAC) System

The system enforces strict operational separation between two fundamental roles:

Dimension Brand Admin (Principal) Sub-Admin (Regional Operator)
Geographic Scope All Indian States & Cities (Nationwide visibility). Strictly restricted to assigned States & Cities.
Navigation Menus Loads dynamic CRM modules plus full Operations suite (Sub-Admins, Permissions, Reports). Dynamically resolved strictly from POST /sub-admin-sidebar response.
Team Management Can create, edit, activate/deactivate Sub-Admins, and configure their permission matrix. Zero access to team management pages.
Lead Assignment Can assign to any operator, trigger auto-assignment, or confirm out-of-territory overrides. Can only manage leads assigned to them or within their territory boundaries.
Reporting & Analytics Full access to state-wise demand distribution and operator conversion metrics. No access to executive reporting suite.

7. Dynamic Navigation & Route Guard Engine

Instead of hardcoding client-side routes, navigation items are built dynamically from server responses:

7.1 Slug-to-Module Resolution Engine (permissionResolver.js)

The backend sends permission tags as human titles or slugs (e.g. "Customer Enquiry", "quotes_enquiry", "Leads"). The resolver normalizes these strings to prevent breakage from backend naming variations: 

export const resolveSlugToModule = (slug = "") => {
  if (!slug) return null;
  const clean = String(slug).trim().toLowerCase().replace(/[^a-z0-9]/g, "");

  if (clean.includes("enquir") || clean.includes("inquir")) return MODULES.CRM_ENQUIRIES;
  if (clean.includes("quote")  || clean.includes("quotation")) return MODULES.CRM_QUOTES;
  if (clean.includes("lead")) return MODULES.CRM_LEADS;
  if (clean.includes("followup") || clean.includes("follow")) return MODULES.CRM_FOLLOWUPS;
  if (clean.includes("report")) return MODULES.REPORTS;
  if (clean.includes("profile")) return MODULES.PROFILE;
  if (clean.includes("dashboard")) return MODULES.DASHBOARD;

  return slug;
};

7.2 Route Protection Guards

  • PrivateRoute: Ensures a valid token and recognized role exist in session. If absent, redirects to /login.
  • PublicRoute: Prevents authenticated users from seeing guest pages (redirects to /dashboard).
  • PermissionRoute: Evaluates if the authenticated user possesses the specific module permission. Supports an adminOnly prop that immediately blocks Sub-Admins.
  • PermissionGate: In-component conditional wrapper that renders buttons or actions only if the user has granular action permissions (e.g. quotes:export).

8. CRM Operations Engine & Business Workflows

8.1 Leads Management & Unified Pipeline (AllLeads.jsx)

The master leads register aggregates all prospective equipment buyers into a high-performance interactive table:

  • Tabs: All Leads (complete visible dataset), Unassigned Leads (inbound queue requiring action), and My Leads (leads assigned to the logged-in operator).
  • Multi-Field Search: Real-time filtering across customer name, phone, lead code, machine interest, city, and state.
  • Status Filters: Filters across standardized statuses: New, Assigned, Contacted, Follow-up, Quote Sent, Won, and Lost.
  • Exporting: Instant client-side CSV generation matching active query filters.

8.2 Customer Enquiries Workflow (CustomerEnquiry.jsx)

Direct integration with POST /premium-brand-quotes-enquiry. Features pagination controls, quick phone-calling triggers (tel:), and one-click lead drawer inspection.

8.3 Feature Equipment Quotation Requests (FeatureEquipmentQuotes.jsx)

Direct integration with POST /get-feature-equipment-quotes. Enriches product-specific quotation requests with CRM deal stages and pricing discussions.

8.4 360° Lead Detail Drawer (LeadDetail.jsx)

Sliding off-canvas drawer that presents an operational cockpit for any lead:

  • Activity Timeline: Chronological history displaying calls, emails, notes, meetings, and stage changes.
  • Customer History: Lifetime value and past inquiries associated with the customer's phone number.
  • Log Activity Tab: Instant form to log call notes, meeting summaries, or internal remarks.
  • Schedule Follow-Up Tab: Date and time scheduler that automatically populates the FollowUps.jsx pipeline.

9. Geographic Territory Management & Workload Auto-Assignment Engine

Lead routing is governed by an automated, workload-aware decision engine implemented in utils/accessRules.js:

Auto-Assignment Logic Flow
1. Extract Lead Location: Identify the target state and city from inbound inquiry data.
2. Query Candidate Pool: Scan all Sub-Admins in the current brand account.
3. Evaluate Operational Eligibility: Candidate must meet three conditions:
• Account status is active
• Has view AND update permissions for this CRM type (e.g. leads:view + leads:update)
• Territory coverage: Operator's assigned territory state matches lead state, AND (cities include "ALL" OR lead city).
4. Workload Balancing Calculation: For all eligible candidates, compute active open burden: 
openCount = leads.filter(l => l.assigned_to === member.id && l.status !== "won" && l.status !== "lost").length
5. Final Execution: Automatically assign the lead to the operator with the minimum active count. Record the automated routing decision in the lead activity timeline.

Admin Manual Territory Override

If a Brand Admin manually assigns a lead to an operator whose territories do not cover the lead's state/city, the system displays an Override Confirmation Dialog. Upon confirmation, the assignment proceeds and is logged with a permanent audit record:

"Admin territory override assignment by [Admin Name]. Reason: Out-of-territory manual assignment override confirmed."

Global Error Handling & Toast Deduplication (axios.js)

The response interceptor formats errors and deduplicates toasts using message hashes:

  • HTTP 401 Unauthorized: Clears localStorage session, triggers toast "Session expired", and forces redirect to /login.
  • HTTP 403 Forbidden: Displays "You are not authorized" alert.
  • HTTP 422 Validation Error: Parses nested errors payload and displays the first field validation error message.
  • HTTP 500+ Server Error: Displays graceful server error notice without crashing client components.

16. Production Deployment & Optimization Recommendations

16.1 Nginx Static Hosting Configuration

server {
    listen 80;
    server_name partners.equipmentsdekho.com;
    root /var/www/partners-brand/dist;
    index index.html;

    # Gzip compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}

16.2 Strategic Engineering Recommendations

  1. Route-Level Code Splitting (React.lazy): Split heavy pages (CustomerEnquiry.jsx, FeatureEquipmentQuotes.jsx, CRMReports.jsx) using dynamic imports to reduce initial bundle size below 200 kB.
  2. IndexedDB Offline Caching: Integrate Dexie.js for client-side CRM caching so field operators can view lead contact details and past notes during temporary network outages.
  3. Real-Time SSE / WebSocket Alerts: Implement Server-Sent Events to automatically trigger new lead notifications without requiring manual table refreshes.
  4. E2E Playwright Suite: Automate critical test flows (Admin permission assignment, out-of-territory override confirmation, and quotation PDF generation).
